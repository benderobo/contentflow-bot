## 1. ЦВЕТОВАЯ ПСИХОЛОГИЯ

### Текущее состояние
- Основной акцент: `#7c6af7` (фиолетовый) — творчество, воображение, но НЕ доверие и НЕ премиальность
- Фон: `#0f0f13` — холодный, «технический» чёрный
- Текст: `#e8e8f0` — нейтральный
- CTA-кнопка: градиент фиолетового — теряется на фоне аналогичных оттенков

### Проблемы
| Элемент | Проблема | Психологический эффект |
|---------|----------|----------------------|
| Фиолетовый акцент | Ассоциируется с «дёшево-креатив», не с премиум-услугой | Пользователь не воспринимает сервис как дорогостоящий |
| Нет золотого/янтарного | Золото = доверие + роскошь в wedding-индустрии | Потеря конверсии у премиум-сегмента |
| CTA не выделяется | Цвет кнопки ≈ цвет фона панелей | «Banner blindness» — мозг фильтрует однотонные зоны |
| `--muted: #6b6b85` | Слишком тусклый — текст теряется | Пользователь пропускает важную информацию |

### Рекомендации
1. **Добавить золотой/янтарный** (`#C9A84C` / `#D4A843`) как CTA-цвет — доверие + роскошь
2. **Повысить контраст muted-текста** до `#8b8ba0` — читаемость без потери иерархии
3. **Двойной акцент**: фиолетовый для навигации/выбора, золотой для конверсионных действий
4. **Фон**: сделать чуть теплее `#111118` — меньше «холодный техно», больше «утешительный»

## 2. УПРАВЛЕНИЕ ВНИМАНИЕМ (Eye Tracking / Visual Hierarchy)

### Текущая воронка
```
Header (логотип + нав) → Галерея шаблонов → Превью → Форма
```

### Проблемы
| Проблема | Где | Эффект |
|----------|-----|--------|
| 3 колонки одновременно | Desktop workspace | Cognitive overload — глаза не знают куда смотреть第一步 |
| Нет визуального «входа» | Нет hero-зоны или подсказки | Пользователь теряется при первом входе |
| Step indicators не привязаны к контенту | Header,远离 основного контента | Шаги незаметны — не мотивируют |
| Превью-панель пуста по умолчанию | Центральная колонка | «Пустой экран» = отток 40% пользователей |
| Форма справа (последняя) | Форма в правой колонке | На desktop пользователь не замечает её (правый盲ик) |

### Рекомендации
1. **Приветственный state**: показать подсказку-тутор при пустом превью (что делать第一步)
2. **Step indicators внизу формы** — привязать к месту действия
3. **Пустое превью**: заменить на интерактивный placeholder с анимацией выбора шаблона
4. **Desktop layout**: перестроить в 2 колонки (галерея+превью слева, форма справа) —减少 когнитивной нагрузки
5. **Mobile**: оставить табы, но добавить визуальный progress bar вместо step-индикаторов

## 3. НЕЙРОМАРКЕТИНГ

### 3.1 CTA-оптимизация
| Текущий элемент | Проблема | Решение |
|-----------------|----------|---------|
| Кнопка «Отправить заявку →» | Обычный текст, нет ценности | «Получить мой сайт →» — benefit-driven |
| Нет hover-анимации ценности | Просто translateY(-1px) | Добавить glow-эффект золотым цветом |
| Нет social proof рядом с CTA | Пустое пространство | «Уже 127 сайтов создано» под кнопкой |
| Размер шрифта 12px | Мало для primary CTA | Увеличить до 14px, font-weight: 700 |

### 3.2 Потерянные возможности
| Нейромаркетинг-принцип | Текущее состояние | Рекомендация |
|------------------------|-------------------|--------------|
| **Social Proof** | Отсутствует полностью | Добавить счётчик «127 сайтов создано» + «4.9 ★ рейтинг» |
| **Scarcity** | Отсутствует | «Осталось 3 свободных места на этой неделе» (даже как маркетинг) |
| **Loss Aversion** | Нет | «Не упустите — ваш сайт готов за 1 минуту» |
| **Anchoring** | Нет цен |
| **Commitment** | Шаги не привязаны к прогрессу | Прогресс-бар с % заполнения |
| **Endowment Effect** | Шаблон выбирается, но не «принадлежит» | После выбора: «Ваш шаблон: Dark Romance» с кнопкой «Изменить» |
| **Peak-End Rule** | Отправка = тост и всё | Финальный экран с анимацией + «Что дальше?» |

### 3.3 Микровзаимодействия
| Элемент | Сейчас | Улучшение |
|---------|--------|-----------|
| Выбор шаблона | `border-color` transition | Scale 1.02 + glow + звуковой feedback (опционально) |
| Hover на карточках | `translateY(-1px)` | Subtle scale 1.01 + shadow expansion |
| Бюджет-выбор | Просто border | Radio-button-style с анимированным заполнением |
| Отправка формы | Shimmer + text change | Конфетти-анимация + скролл к верху + social proof |
