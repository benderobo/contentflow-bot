# Insite Studio

Web-based design studio for creating and managing insite client projects. Python Flask backend with HTML5/JavaScript frontend.

## Features

- Project management interface (`index.html`, `admin.html`)
- Studio workspace (`studio.html`)
- Python API server (`api_server.py`)
- UX audit and documentation (`UX_AUDIT.md`)

## Setup

```bash
pip install -r requirements.txt
python api_server.py
```

Server runs on `http://localhost:5000`

## Frontend

- `index.html` - Main dashboard
- `admin.html` - Admin interface
- `studio.html` - Design workspace

## Documentation

See `UX_AUDIT.md` for UX research and design decisions.
